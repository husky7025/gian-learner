# 기안 학습기

샘플 기안(.hwpx)을 올리면 양식을 학습하고, 입력한 내용으로 **같은 서식의 .hwpx 파일**을 만들어 주는 로컬 웹 앱입니다.

## 내려받기 (선생님용)
**https://github.com/husky7025/gian-learner/releases** 에서 최신 `gian-learner-v…-windows.zip`을 받아 압축을 풀고 `기안학습기.exe`를 실행하세요. Python 설치가 필요 없습니다. 자세한 내용은 [docs/사용안내.txt](docs/사용안내.txt).

## 실행 (개발용)
`기안학습기 실행.bat` 을 더블클릭하면 브라우저에서 http://127.0.0.1:8765 이 열립니다. 검은 창을 닫으면 앱이 꺼집니다.
(처음 실행할 때 필요한 파이썬 패키지를 자동으로 설치합니다. Python 3.10 이상 필요)

처음 실행한 뒤 ⚙ 설정에서 **바탕화면 바로가기**와 **컴퓨터 켤 때 자동 실행**을 켤 수 있습니다. 바로가기로 실행하면 검은 창 없이 동작하고, 끌 때는 왼쪽 아래 **⏻ 앱 종료**를 누릅니다.

## 사용 순서
1. 왼쪽 위 **기안 / 품의 / 가정통신문** 탭을 고르고, 필요하면 그 안에 양식을 더 만들기 (예: 물품 품의, 강사비 품의)
2. **샘플** 탭에 같은 양식의 기안 .hwpx 2~5개 올리기 → 자동 학습
3. **학습 내용** 탭에서 고정/입력칸 확인, 필요하면 바꾸기
4. **작성** 탭에서 내용 입력 → **HWPX 만들기**

## 양식 꾸러미 (.gianpack)
- **기본 양식 꾸러미**: 처음 화면의 「⭐ 기본 양식 꾸러미로 바로 시작하기」 또는 ⚙ 설정에서 불러오면 기안·품의·가정통신문 예시 양식이 학습된 상태로 들어옵니다. (가상의 예시 내용으로 만든 문서입니다)
- **나눠 주기**: ⚙ 설정 → 양식 꾸러미 → 내보내기. 내보내기 전에 전화번호·이메일·주민번호·이름 등 개인정보로 보이는 글자를 검사해 보여 줍니다. 작성자 정보·미리보기 그림·샘플 파일 이름은 자동으로 지웁니다.
- **받기**: ⚙ 설정 → 꾸러미 가져오기, 또는 샘플 탭에 .gianpack 파일을 끌어다 놓기.

## 학습 방식
- 번호 체계(1. → 가. → 1) → 가) → (1) …)를 인식해 본문을 "제목: 값" 항목으로 나눕니다.
- 샘플끼리 비교해 모두 같은 값은 기본값으로, 다른 값은 빈칸(예시 표시)으로 둡니다.
- 서식은 기준 샘플 파일을 그대로 복사해 글자만 바꾸므로 글꼴·문단 모양·여백이 유지됩니다.
- 붙임 번호와 「끝.」 표시는 자동으로 붙습니다.
- 표: '제목 칸 | 값 칸' 형태의 값 칸은 입력칸, 머리글 줄은 고정으로 잡습니다. 학습 내용 탭에서 칸을 눌러 바꿀 수 있습니다.
- 입력 도우미: 날짜(2026. 11. 8.(일)), 금액(금113,560원(금일십일만삼천오백육십원))을 커서 위치에 넣습니다.

## 데이터 저장
- 위치: `%LOCALAPPDATA%\기안학습기` (OneDrive 동기화 폴더 밖, 이 PC 전용)
- 양식·샘플·생성 이력이 저장되어 껐다 켜도 남습니다.
- 초기화·삭제 직전 상태는 자동 백업(최근 20개)되어 ⚙ 메뉴에서 되돌릴 수 있습니다.

## 보안
- 서버는 127.0.0.1에서만 열리고, 다른 컴퓨터·다른 사이트에서 오는 요청은 거부합니다.
- 인터넷 서비스(DB·AI 등)를 쓰지 않습니다.

## 개발 참고
- 샘플 형식: .hwpx(서식까지 학습) · .odt/.pdf(`app/convert.py`가 글자·번호 구조만 읽어 기본 서식 hwpx로 변환)
- exe 만들기: `pip install pyinstaller` 후 `python tools/build_exe.py` → `dist/gian-learner-v<버전>-windows.zip`
- 출시: `app/version.py`의 버전을 올리고 커밋 → `git tag v<버전>` → `git push --tags` 하면 GitHub Actions가 zip을 만들어 Releases에 올림
- 기본 꾸러미 다시 만들기: `python tools/make_default_pack.py --gian 기안.hwpx --pumui 품의.hwpx --gatong 가정통신문.hwpx`
  (서식만 빌려 쓰고 글자는 스크립트 안의 가상 예시로 모두 바꿉니다. 빠진 칸이 있으면 멈춥니다.)

## 현재 한계
- 표의 행 추가·삭제는 아직 안 됩니다(칸 내용만 편집).
- 구버전 .hwp는 한글에서 HWPX로 저장해 올려야 합니다.

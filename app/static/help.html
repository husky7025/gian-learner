1. 이 프로그램은 무엇인가요?

예전에 쓴 기안 파일 몇 개를 보여 주면, 그 모양(양식)을 스스로 익혀서, 새 내용만 적으면 똑같은 모양의 한글 파일(.hwpx)을 만들어 주는 프로그램입니다.

💡 예를 들어 「물품 구입 품의」를 여러 번 쓰셨다면, 그 파일들을 올려 두고 다음부터는 건명·금액·품목만 적으면 번호, 줄 맞춤, 「붙임」, 「끝.」까지 알아서 맞춰 줍니다.
🔒 이 프로그램은 이 컴퓨터 안에서만 작동합니다. 기안 내용이 인터넷으로 나가지 않고, 다른 사람이 볼 수 없습니다. 껐다 켜도 익힌 내용은 그대로 남아 있습니다. (새 버전이 나왔는지 확인할 때만 최신 버전 번호를 인터넷으로 물어보며, 설정에서 끌 수 있습니다)

✨ AI로 작성하기 (가장 쉬운 방법)

날짜와 간단한 내용만 적으면, AI가 이 학교의 예전 기안과 똑같은 모양과 말투로 기안 전체를 써 줍니다.

  1. 왼쪽에서 분류와 양식을 고르고 ✍ 작성을 누릅니다. (샘플이 학습되어 있어야 합니다 → 6번)
  2. 맨 위 보라색 상자에 무엇을 기안할지 한두 줄 적습니다.
    예) 「12월 3일 도서부 동아리 도서 20권 구입, 36만 4천 원, 견적서·도서목록 첨부」
  3. 기안일(오늘 날짜가 기본)을 확인하고 ✨ AI로 작성하기를 누릅니다.
  4. 잠시 뒤 아래 칸들이 채워집니다. 오른쪽 미리보기를 읽어 보고, 틀린 곳은 칸에서 직접 고칩니다.
  5. 📄 HWPX 만들기를 누르면 끝입니다.
💡 잘 쓰게 하는 요령
· 날짜, 시간, 장소, 대상, 금액, 수량, 붙임처럼 사실은 꼭 적어 주세요. AI는 모르는 사실을 지어내지 않고 「○○」으로 비워 둡니다.
· 요일과 「금○○원(금○○원)」 한글 금액은 프로그램이 다시 계산해 바로잡습니다.
· 마음에 안 들면 내용을 조금 바꿔 다시 눌러 보세요.
⚠ AI가 쓴 기안은 반드시 한 번 읽어 보고 내세요. 날짜·금액·대상 같은 사실이 맞는지는 사람이 확인해야 합니다.

어떤 AI를 쓸까요? (⚙ 설정 → 🤖 AI 작성 설정)

로컬 AI (기본)이 컴퓨터 안에서만 작동합니다. 인터넷 전송·비용 없음. 대신 「Ollama」라는 프로그램 설치가 필요하고, 메모리 16GB 이상 컴퓨터를 권장합니다. 문장 품질은 아래 셋보다 낮을 수 있고 1~3분 걸릴 수 있습니다.
ClaudeAnthropic의 AI. 공문서 문장 품질이 좋습니다. API 키 필요(사용한 만큼 요금).
GeminiGoogle의 AI. API 키 필요(무료 사용량이 있을 수 있음).
ChatGPTOpenAI의 AI. API 키 필요(사용한 만큼 요금).
🔒 Claude · Gemini · ChatGPT를 쓰면 적은 내용과 샘플 기안 글이 그 회사 서버로 보내집니다. 이때 전화번호·이메일·주민번호와 「교사 ○○○」, 「성명: ○○○」 같은 이름은 가려서 보냅니다. 처음 쓸 때 한 번 동의를 묻습니다. 학생 개인정보가 들어 있는 기안이라면 로컬 AI를 쓰는 것이 가장 안전합니다.

API 키 받는 방법 (Claude · Gemini · ChatGPT)

API 키는 AI를 쓰기 위한 비밀번호 같은 긴 글자입니다. 다른 사람에게 알려 주지 마세요.

Claudeconsole.anthropic.com 가입 → 결제 수단 등록(Billing) → API Keys → Create Key → 나온 키(sk-ant-…)를 복사
Geminiaistudio.google.com (구글 계정으로 로그인) → Get API key → Create API key → 복사
ChatGPTplatform.openai.com 가입 → 결제 수단 등록(Billing) → API keys → Create new secret key → 복사 (ChatGPT 유료 구독과는 별개입니다)
  1. ⚙ 설정 · 백업 · 초기화 → 🤖 AI 작성 설정에서 「사용할 AI」를 고릅니다.
  2. API 키 칸에 복사한 키를 붙여 넣고(Ctrl+V) 저장을 누릅니다. 키는 이 컴퓨터에만 암호화되어 저장되고, 화면에는 끝 4자리만 보입니다.
  3. 목록 불러오기를 눌러 「✔ 연결됨」이 나오면 성공입니다. 모델 칸을 눌러 원하는 모델을 고르고 AI 설정 저장을 누릅니다.

로컬 AI(Ollama) 설치하기

  1. 인터넷에서 ollama.com → Download → Windows용을 받아 설치합니다. (학교 PC에 설치 권한이 없으면 정보 담당 선생님께 문의하세요)
  2. 시작 메뉴에서 명령 프롬프트(cmd)를 열고 아래를 적은 뒤 Enter — AI 모델을 받습니다(약 5GB, 한 번만).
    ollama pull qwen2.5:7b
  3. ⚙ 설정 → 🤖 AI 작성 설정 → 「로컬 AI」 → 목록 불러오기에서 받은 모델이 보이면 끝입니다.
💡 컴퓨터가 느리면 더 작은 모델(ollama pull gemma3:4b)을, 성능이 좋으면 더 큰 모델을 받아 고르세요. 큰 모델일수록 문장이 좋아집니다.

  2. 양식 목록 — 그 분류 안의 양식들입니다. (예: 물품 품의, 강사비 품의) 누르면 그 양식이 열립니다.
  3. 화면 탭 — ✍ 작성(내용 적기), 🧠 학습 내용(익힌 모양 확인), 📁 샘플(예전 기안 올리기), 🕘 이력(예전에 만든 파일)

3. 처음 시작하기

  1. 프로그램을 처음 켜면 가운데에 ⭐ 기본 양식 꾸러미로 바로 시작하기 버튼이 보입니다. 이 버튼을 한 번 누르세요.
  2. 기안 · 품의 · 가정통신문 예시 양식이 들어옵니다. 이제 바로 기안을 만들어 볼 수 있습니다.
  3. 예시 양식이 내 기안과 모양이 다르다면, 6. 내 기안으로 학습시키기를 따라 내 기안을 올려 주세요.
💡 버튼이 안 보이면 왼쪽 아래 ⚙ 설정 · 백업 · 초기화 → ⭐ 기본 양식 꾸러미 불러오기를 누르셔도 됩니다.

4. 기안 만들기

  1. 왼쪽 위에서 기안 / 품의 / 가정통신문 중 하나를 누릅니다.
  2. 그 아래 양식 목록에서 쓸 양식을 누릅니다. (파랗게 표시되면 선택된 것입니다)
  3. 오른쪽 위 ✍ 작성이 눌려 있는지 확인합니다.
  4. 빈칸을 마우스로 한 번 누른 뒤 내용을 적습니다. 회색 글씨 「예) …」는 예전 기안에 있던 예시이니 참고만 하세요.
    • 회색 줄은 매번 똑같이 들어가는 부분이라 고칠 필요가 없습니다.
    • 노란 칸은 직접 적는 부분입니다.
    • 번호(1. 가. 1))는 자동으로 붙습니다. 직접 적지 마세요.
  5. 오른쪽 미리보기에서 완성될 모습을 확인합니다.
  6. 아래의 📄 HWPX 만들기를 누르면 파일이 만들어집니다. → 5. 만든 파일 찾기

항목을 더하거나 빼고 싶을 때

각 줄 오른쪽의 작은 버튼을 씁니다.

＋바로 아래에 같은 단계의 항목을 하나 더 만듭니다.
✕그 항목을 지웁니다.
↑ ↓항목 순서를 위·아래로 옮깁니다.
⇥한 단계 안쪽으로 넣습니다. (예: 「2.」 → 「가.」)
⇤한 단계 바깥쪽으로 뺍니다. (예: 「가.」 → 「2.」)

목록 맨 아래의 ＋ 항목 추가, ＋ 하위 항목으로도 더할 수 있고, 「다른 샘플의 항목」 버튼(예: ＋ 기간)을 누르면 예전 기안에 있던 항목이 바로 들어옵니다.

붙임

붙임 칸에 「견적서 1부」처럼 적으면 됩니다. 여러 개면 번호(1. 2.)와 맨 끝의 「끝.」이 자동으로 붙습니다.

표가 있는 양식(가정통신문 등)

표가 실제 모양대로 보이고, 노란 칸에 바로 적으면 됩니다. 칸 안에서 Enter를 누르면 줄이 바뀝니다.

💾 적는 내용은 자동으로 임시저장됩니다. 실수로 창을 닫아도 다시 열면 그대로 있습니다. 처음부터 다시 쓰려면 처음 상태로를 누르세요.

5. 만든 파일 찾기 · 쓰기

  1. 📄 HWPX 만들기를 누르면 파일이 「다운로드」 폴더에 저장됩니다. 브라우저 오른쪽 위에 내려받기 표시(⬇)가 잠깐 나타납니다.
  2. 파일을 찾으려면 키보드에서 Ctrl + J를 누르세요. 내려받은 파일 목록이 열립니다. 파일 이름을 누르면 한글로 열립니다.
  3. 또는 바탕화면 아래 파일 탐색기(노란 폴더 모양) → 왼쪽의 다운로드를 누르세요.

K-에듀파인에 붙여 넣기

  1. 만든 파일을 한글로 엽니다.
  2. Ctrl + A (전체 선택) → Ctrl + C (복사)
  3. K-에듀파인 기안 작성 화면의 본문을 누르고 Ctrl + V (붙여 넣기)
💡 파일 이름은 「건명」이나 「제목」으로 자동으로 정해집니다. 바꾸고 싶으면 작성 화면 맨 위 파일 이름 칸에 적으세요.

6. 내 기안으로 학습시키기

프로그램이 내 기안 모양을 익히려면, 같은 종류의 예전 기안 파일을 2~5개 보여 주면 됩니다. 이 파일을 「샘플」이라고 부릅니다.

  1. 왼쪽에서 분류(예: 품의)와 양식을 고릅니다. 새 양식이 필요하면 왼쪽 아래 칸에 이름(예: 물품 품의)을 적고 ＋ 추가를 누르세요.
  2. 오른쪽 위 📁 샘플을 누릅니다.
  3. 파일 선택을 누르고, 예전 기안 파일을 고른 뒤 열기를 누릅니다. 여러 개를 한 번에 고르려면 Ctrl을 누른 채 파일을 하나씩 누르세요.
  4. 「✔ ○개를 학습했습니다」가 나오면 끝입니다. ✍ 작성으로 가서 써 보세요.
💡 끌어다 놓기도 됩니다: 파일 탐색기에서 파일을 마우스로 꾹 누른 채 끌고 와서, 점선 상자 위에서 손을 떼면 됩니다.

올릴 수 있는 파일

.hwpx✅ 가장 좋습니다. 글꼴·줄 간격·표 모양까지 그대로 익힙니다.
.odt✅ K-에듀파인에서 내려받은 「본문」 파일. 글자와 번호 모양만 익히고, 서식은 기본 모양이 됩니다.
.pdf✅ 글자와 번호 모양만 익힙니다. (스캔한 그림 PDF는 안 됩니다)
.hwp⚠ 옛날 한글 파일. 한글에서 열고 파일 → 다른 이름으로 저장 → 파일 형식 「HWPX」로 저장해서 올려 주세요.
.ozd⚠ 지출품의서 같은 오즈 문서. K-에듀파인에서 문서를 열고 PDF로 저장(또는 인쇄 → 「Microsoft Print to PDF」)해서 그 PDF를 올려 주세요.
⚠ 종류가 다른 기안을 섞지 마세요. 「물품 품의」와 「강사비 품의」처럼 항목이 다르면 양식을 따로 만들어 올리는 것이 좋습니다. 섞여 있으면 화면 위에 주의 문구가 나옵니다.
💡 .odt·.pdf만 올리면 서식이 기본 모양이 됩니다. .hwpx를 하나라도 같이 올리면 그 서식을 따릅니다.

7. 학습이 이상할 때

고칠 부분이 회색(고정)으로 나올 때 / 그 반대일 때

  1. 🧠 학습 내용을 누릅니다.
  2. 줄 오른쪽의 입력칸으로 / 고정으로 버튼을 누르면 바뀝니다.
  3. 표는 칸을 직접 누르면 고정 ↔ 입력칸이 바뀝니다.

엉뚱한 샘플을 올렸을 때

📁 샘플에서 그 파일 옆의 빼기를 누르세요. 남은 샘플로 다시 익힙니다.

처음부터 다시 하고 싶을 때 (초기화)

📁 샘플 맨 아래의 이 양식 학습 초기화를 누르세요.

🛟 걱정하지 마세요. 초기화나 삭제를 하기 직전 상태는 자동으로 백업됩니다. ⚙ 설정 · 백업 · 초기화 → 백업 목록에서 이 상태로 되돌리기를 누르면 돌아갑니다.

8. 날짜 · 금액 쉽게 넣기

작성 화면 위쪽의 입력 도우미를 쓰면 공문서 모양에 맞게 넣어 줍니다.

  1. 먼저 날짜나 금액을 넣을 빈칸을 한 번 누릅니다. (깜빡이는 막대가 생기는 곳에 들어갑니다)
  2. 날짜: 날짜 칸에서 날짜를 고르고 📅 날짜 넣기 → 「2026. 11. 8.(일)」 모양으로 들어갑니다. 오늘은 오늘 날짜를 넣습니다.
  3. 금액: 금액 칸에 숫자만(예: 113560) 적고 💰 금액 넣기 → 「금113,560원(금일십일만삼천오백육십원)」으로 들어갑니다.

9. 예전에 만든 기안 다시 쓰기

  1. 🕘 이력을 누르면 이 양식으로 만든 파일 목록이 나옵니다.
  2. 다시 받기: 그 파일을 다시 내려받습니다.
  3. 불러오기: 그때 적은 내용을 작성 화면으로 가져옵니다. 날짜·금액만 바꿔서 새로 만들 때 편합니다.

10. 다른 선생님과 나누기 (양식 꾸러미)

잘 익힌 양식을 파일 하나(.gianpack)로 만들어 다른 선생님께 드릴 수 있습니다. 받은 선생님은 샘플을 모으지 않아도 바로 쓸 수 있습니다.

보내는 선생님

  1. ⚙ 설정 · 백업 · 초기화 → 📤 꾸러미 내보내기를 누릅니다.
  2. 나눌 양식에 체크(☑)하고 개인정보 검사하기를 누릅니다.
  3. 전화번호·이름 같은 개인정보로 보이는 글자가 있으면 빨간 글씨로 보여 줍니다. 괜찮으면 내보내기를 누릅니다.
  4. 「다운로드」 폴더에 생긴 .gianpack 파일을 메신저 등으로 보냅니다.
⚠ 개인정보가 나오면, 그 샘플을 한글에서 고쳐 저장한 뒤 다시 올리고 내보내는 것이 안전합니다. (작성자 이름·미리보기 그림·파일 이름은 자동으로 지워집니다)

받는 선생님

⚙ 설정 · 백업 · 초기화 → 📥 꾸러미 가져오기 → 받은 파일 선택. 또는 📁 샘플 상자에 끌어다 놓으세요.

11. 켜고 끄기

켜기

「기안학습기」 폴더의 기안학습기.exe를 두 번 누르면 브라우저에 화면이 열립니다.

더 편하게 (한 번만 해 두면 됩니다)

  1. ⚙ 설정 · 백업 · 초기화 → 바탕화면 바로가기 만들기 → 다음부터는 바탕화면의 「기안 학습기」 아이콘을 두 번 누르면 됩니다.
  2. ☑ 컴퓨터를 켜면 자동으로 실행에 체크하면, 컴퓨터를 켤 때 뒤에서 미리 켜져 있어 아이콘을 누르면 바로 열립니다.

끄기

왼쪽 아래 ⏻ 앱 종료를 누르세요. 브라우저 탭만 닫으면 프로그램은 뒤에서 계속 켜져 있습니다. (켜져 있어도 문제는 없습니다)

새 버전으로 바꾸기

새 버전이 나오면 화면 맨 위에 🎉 새 버전 v○.○.○이 나왔습니다 라는 초록색 안내가 뜹니다.

  1. 안내의 받으러 가기를 누릅니다. 내려받기 페이지가 열립니다.
  2. 페이지 아래쪽 Assets에서 gian-learner-v○.○.○-windows.zip을 눌러 내려받습니다.
  3. 왼쪽 아래 ⏻ 앱 종료로 지금 프로그램을 끕니다.
  4. 예전 「기안학습기」 폴더를 지우고, 새 zip을 같은 자리에 압축 풀기 합니다.
  5. 새 폴더의 기안학습기.exe를 두 번 누르면 끝입니다.
✅ 익힌 양식·샘플·이력은 그대로 남습니다. (프로그램 폴더가 아닌 사용자 폴더에 저장되어 있기 때문입니다)
💡 폴더 위치를 바꿨다면 ⚙ 설정에서 바탕화면 바로가기를 다시 만들어 주세요. 지금 바로 알아보려면 ⚙ 설정의 지금 확인을 누르세요. 알림이 필요 없으면 ⚙ 설정에서 「새 버전이 나오면 알려 주기」 체크를 끄면 됩니다.

※ 새 버전 확인 때는 인터넷으로 최신 버전 번호만 물어봅니다. 기안 내용은 보내지 않습니다. 인터넷이 막혀 있으면 안내가 뜨지 않을 뿐 사용에는 문제가 없습니다.

12. 자주 묻는 질문

AI로 작성하기를 누르면 오류가 나요. · 「API 키가 올바르지 않습니다」 → ⚙ 설정에서 키를 다시 붙여 넣고 저장하세요.
· 「로컬 AI가 실행 중이 아닙니다」 → Ollama를 설치·실행하고 모델을 받았는지 확인하세요. → AI로 작성하기
· 「사용량 한도」 → 잠시 뒤 다시 하거나, 그 회사 사이트에서 결제 상태를 확인하세요.
· 학교 인터넷이 AI 사이트를 막는 경우도 있습니다. 그때는 로컬 AI를 쓰세요.
파란 「Windows의 PC 보호」 창이 떠요. 개인이 만든 프로그램이라 나오는 안내입니다. 추가 정보를 누른 뒤 실행을 누르세요. 처음 한 번만 나옵니다.
아이콘을 눌렀는데 화면이 안 열려요. 10초쯤 기다려 보세요. 그래도 안 열리면 브라우저(크롬·엣지) 주소창에 127.0.0.1:8765 를 적고 Enter를 누르세요. 그래도 안 되면 컴퓨터를 다시 켠 뒤 아이콘을 눌러 주세요.
만든 파일이 어디 있는지 모르겠어요. 브라우저에서 Ctrl + J를 누르면 내려받은 파일 목록이 나옵니다. → 5. 만든 파일 찾기
컴퓨터를 끄면 익힌 내용이 없어지나요? 아니요. 이 컴퓨터에 저장되어 있어서 껐다 켜도, 새 버전으로 바꿔도 그대로 남습니다. 단, 다른 컴퓨터에서는 따로 익혀야 합니다. (꾸러미로 옮길 수 있습니다 → 10번)
제 기안 내용을 다른 사람이 볼 수 있나요? 아니요. 이 프로그램은 이 컴퓨터 안에서만 작동하고 인터넷으로 내용을 보내지 않습니다. 같은 학교 다른 컴퓨터에서도 접속할 수 없습니다.
번호가 이상하게 붙어요. (예: 「가.」가 「2.」로 나와요) 그 줄 오른쪽의 ⇥(안쪽으로) / ⇤(바깥쪽으로)를 눌러 단계를 맞춰 주세요. 번호는 단계에 따라 자동으로 바뀝니다.
잘못 눌러서 지웠어요. 되돌릴 수 있나요? 초기화·삭제 직전 상태는 자동으로 백업됩니다. ⚙ 설정 · 백업 · 초기화 → 백업 목록 → 이 상태로 되돌리기. 작성 중인 글은 자동 임시저장되어 있습니다.
새 버전은 어떻게 받나요? 새 버전이 나오면 화면 위에 초록색 안내가 뜹니다. → 새 버전으로 바꾸기
직접 받으려면 인터넷 주소 github.com/husky7025/gian-learner/releases 에서 맨 위의 zip 파일을 받아, 기존 「기안학습기」 폴더를 지우고 새로 푼 폴더로 바꾸면 됩니다. 익힌 내용은 그대로 남습니다. (폴더 위치가 바뀌면 바탕화면 바로가기를 다시 만들어 주세요)
한글(hwp) 프로그램이 없어도 되나요? 파일을 만드는 것은 한글이 없어도 됩니다. 만든 파일을 열어 보려면 한글이 필요합니다.

기안 학습기 사용 안내
====================

샘플 기안(.hwpx)을 학습해서, 입력한 내용으로 같은 서식의 한글 문서(.hwpx)를 만들어 주는 프로그램입니다.
이 컴퓨터 안에서만 작동하며, 문서 내용은 인터넷으로 보내지 않습니다.


※ 앱 화면 왼쪽 아래 [📖 사용설명서]에 그림이 들어간 자세한 설명이 있습니다.

1. 처음 실행하기
----------------
 1) 내려받은 zip 파일을 마우스 오른쪽 버튼 → [압축 풀기]로 풉니다.
    (zip 안에서 바로 실행하지 말고 꼭 압축을 풀어 주세요. 예: 문서 폴더나 바탕화면)
 2) 「기안학습기」 폴더 안의 「기안학습기.exe」를 더블클릭합니다.
 3) 잠시 뒤 브라우저(크롬·엣지)에 기안 학습기 화면이 열립니다.

 ※ "Windows의 PC 보호" 파란 창이 뜨면
    → [추가 정보]를 누른 뒤 [실행] 버튼을 누르세요.
    (개인이 만든 프로그램이라 인증서 서명이 없어서 나오는 안내입니다)
 ※ 학교 보안 프로그램이 실행을 막으면 정보 담당 선생님께 문의해 주세요.


2. AI로 바로 쓰기 (가장 쉬운 방법)
---------------------------------
 - [✍ 작성] 화면 맨 위 상자에 「12월 3일 도서 20권 구입, 36만 4천 원, 견적서 첨부」처럼
   간단히 적고 [✨ AI로 작성하기]를 누르면, 예전 기안과 같은 모양으로 기안 전체를 써 줍니다.
 - 쓸 AI는 ⚙ 설정 → 🤖 AI 작성 설정에서 고릅니다: 로컬 AI(기본, 인터넷 전송 없음) / Claude / Gemini / ChatGPT.
   Claude·Gemini·ChatGPT는 각자 API 키가 필요합니다. 받는 방법은 앱의 [📖 사용설명서 → AI로 작성하기]를 보세요.
 - AI가 쓴 내용은 반드시 한 번 읽어 보고 사실(날짜·금액 등)이 맞는지 확인해 주세요.


2-1. 바로 시작하기
----------------
 - 첫 화면의 [⭐ 기본 양식 꾸러미로 바로 시작하기]를 누르면
   기안·품의·가정통신문 예시 양식이 학습된 상태로 들어옵니다.
 - 왼쪽 위 [기안 / 품의 / 가정통신문] 탭에서 양식을 고르고,
   [✍ 작성] 탭에서 내용을 채운 뒤 [📄 HWPX 만들기]를 누르면 다운로드 폴더에 파일이 생깁니다.


3. 내 기안으로 학습시키기
-------------------------
 - [📁 샘플] 탭에 같은 양식의 기안 .hwpx 파일을 2~5개 끌어다 놓으면 자동으로 학습합니다.
 - K-에듀파인에서 내려받은 본문(.odt)이나 .pdf도 올릴 수 있습니다.
   이때는 글자와 번호 구조만 읽어 기본 서식으로 바꿉니다. 원래 글꼴·표 모양까지 살리려면
   .hwpx 샘플을 하나 이상 함께 올려 주세요. (서식은 .hwpx를 따릅니다)
 - 지출품의서 같은 .ozd(오즈 문서)는 바로 읽을 수 없습니다. K-에듀파인에서 문서를 연 뒤
   오즈 뷰어의 [PDF로 저장](또는 인쇄 → 'Microsoft Print to PDF')으로 PDF를 만들어 올려 주세요.
 - 구버전 .hwp 파일은 한글에서 [다른 이름으로 저장 → HWPX]로 바꿔 올려 주세요.
 - [🧠 학습 내용] 탭에서 고정 부분 / 입력칸을 눌러서 바꿀 수 있습니다.
 - 잘못 학습되었으면 [📁 샘플] 탭 아래의 [이 양식 학습 초기화]를 누르세요.
   (지우기 직전 상태는 자동 백업되어 ⚙ 설정에서 되돌릴 수 있습니다)


4. 편하게 쓰기 (⚙ 설정)
-----------------------
 - [바탕화면 바로가기 만들기]: 다음부터 바탕화면 아이콘으로 실행합니다.
 - [컴퓨터를 켜면 자동으로 실행]: 켜 두면 바로가기를 눌렀을 때 바로 열립니다.
 - 앱을 끌 때는 왼쪽 아래 [⏻ 앱 종료]를 누르세요. (브라우저 탭만 닫으면 뒤에서 계속 켜져 있습니다)

 ※ 「기안학습기」 폴더를 다른 곳으로 옮겼다면 바로가기를 다시 만들어 주세요.


5. 다른 선생님과 양식 나누기
---------------------------
 - ⚙ 설정 → 양식 꾸러미 → [📤 꾸러미 내보내기]: 양식을 골라 .gianpack 파일로 저장합니다.
   내보내기 전에 전화번호·이름 등 개인정보로 보이는 글자를 검사해 보여 줍니다.
 - 받은 .gianpack 파일은 ⚙ 설정 → [📥 꾸러미 가져오기]로 불러옵니다.


6. 저장 위치와 새 버전
----------------------
 - 학습 내용은 이 컴퓨터의 사용자 폴더(%LOCALAPPDATA%\기안학습기)에 저장되어,
   프로그램을 껐다 켜거나 새 버전으로 바꿔도 그대로 남습니다.
 - 새 버전이 나오면 앱 화면 위에 초록색 안내가 뜹니다. ([받으러 가기]를 누르세요.
   인터넷으로 최신 버전 번호만 확인하며, ⚙ 설정에서 끌 수 있습니다)
 - 새 버전: https://github.com/husky7025/gian-learner/releases 에서 최신 zip을 받아
   기존 「기안학습기」 폴더를 지우고 새 폴더로 바꾸면 됩니다. (학습 내용은 유지)
 - 문의·오류 신고: https://github.com/husky7025/gian-learner/issues

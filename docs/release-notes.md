## 내려받기

아래 **Assets**의 `gian-learner-v…-windows.zip`을 받으세요. (Windows 10/11, 설치·Python 필요 없음)

1. zip 파일을 마우스 오른쪽 버튼 → **압축 풀기**
2. `기안학습기` 폴더의 **기안학습기.exe** 더블클릭 → 브라우저에 화면이 열립니다
3. 처음이면 **⭐ 기본 양식 꾸러미로 바로 시작하기**를 누르세요

> "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. (서명되지 않은 개인 제작 프로그램이라 나오는 안내입니다)
> 자세한 사용법은 폴더 안의 `사용안내.txt`를 보세요.

## 주요 기능

- 샘플 기안(.hwpx · .odt · .pdf)을 올리면 양식을 학습하고, 입력한 내용으로 같은 서식의 .hwpx를 만듭니다
- 기안 · 품의 · 가정통신문 탭, 표 칸 편집, 날짜·금액(한글 금액) 입력 도우미
- 양식 꾸러미(.gianpack)로 학습된 양식 나누기 — 내보내기 전 개인정보 검사
- 이 컴퓨터 안에서만 작동, 껐다 켜도 학습 내용 유지, 초기화·자동 백업·되돌리기
- 바탕화면 바로가기 · 컴퓨터 켤 때 자동 실행

## 새 버전으로 바꾸기

기존 `기안학습기` 폴더를 지우고 새 zip을 풀면 됩니다. 학습 내용은 사용자 폴더(`%LOCALAPPDATA%\기안학습기`)에 있어 그대로 유지됩니다.
